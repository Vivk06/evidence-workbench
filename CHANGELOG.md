# Changelog

## 1.4.0 — 2026-11-17

This release prepares the plugins for a clean public repository.

- The README starts with one plugin. The catalog and optional tool guide live in `docs/`.
- Paper processing is optional. Writing and audits install without research-papers.
- New profiles inherit project policy. Test ceilings, git restrictions, fixed document
  layouts and session handoffs are optional. Existing profile values stay intact.
- Repository setup checks personal tool settings only when requested.
- Parser and guard tests use synthetic project profiles.
- The public export uses selected current files and excludes private history and decisions.
